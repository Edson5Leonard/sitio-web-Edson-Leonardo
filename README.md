#Proyecto sitio-web-Edson-Rojas

##¿Que contiene?

Este proyecto es un sitio web estatico con HTML, CSS, JavaScript, PHP y imagenes organizados en carpetas.

##¿Cómo abrirlo?

Abre el archivo con visual estudio con "code nombre-de-la-carpeta".

##¿Qué aprendi?

- Cómo organizar un proyecto web.
- Cómo usar Git para controlar versiones.
- Cómo documentar con README.md.
- Cómo crear ramas y trabajar ordenadamente.
